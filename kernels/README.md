# kernels/

The CUDA kernels and how they are built for the Rust host: one copy of the sources, compiled
by Nix into the device image and, for the host, into the reference adapter's library.

| File | What |
|---|---|
| `kernels.h` | The encoder's kernels: pyramid, motion search and smoothing, macroblock statistics, transform, row statistics, quantization, reconstruction, padding |
| `entropy.h` | The entropy coder's kernels (resolve, pack, row and picture sums, scatter) |
| `common.h` | What the kernels share: helpers, the tables' accessors, the record of `vlc_tables.h` |
| `vlc_tables.h` | The variable-length code tables of H.262 Annex B, generated by `gen_tables.py` from the text of the standard |
| `gen_tables.py` | The generator of `vlc_tables.h` (and of `crates/tb-m2v-syntax/src/vlc.rs` with `--rust`) |
| `pipe_kernels.h` | The conversion kernels of the pipeline (scaling, composition, color) |
| `tb_kernel_abi.h` | The records shared with the host, generated by cbindgen from `crates/tb-kernel-abi` (`nix run .#abi-header`; the check `kernels/abi-header-fresh` keeps it equal) |
| `tb_kernels.cu` | Translation unit of the device image (`nvcc -cubin`, sm_89) |
| `tb_kernel_list.h` | The kernels of the image, by name, with the flag that says a kernel uses barriers |
| `tb_kernels_ref.cc` | The same kernels compiled for the host, plus the launcher (`tbk_launch`) |
| `shim/cuda_runtime.h` | Host stand-in for the CUDA header: qualifiers, `blockIdx`/`threadIdx`, intrinsics, barriers |
| `abi_layout.cc` | Prints the layout of every ABI record as C++ sees the generated header |

Built by `nix/kernels.nix`; see `docs/ARCHITECTURE.md` section 6.
